🌐 Hướng Dẫn Host MediPOS Online

💡 Tư Vấn: Nếu bạn chỉ muốn dùng trên 1-2 máy tính, không cần host. Mở file index.html trực tiếp là được!

🎯 Lợi Ích Khi Host Online

  • ✅ Truy cập từ bất kỳ máy tính nào
  • ✅ Nhân viên dùng chung 1 cơ sở dữ liệu
  • ✅ Dữ liệu đồng bộ realtime
  • ✅ Chia sẻ link cho khách hàng (nếu muốn)
  • ✅ Khôi phục dự phòng tự động

1️⃣ LOCALHOST - HOST TRÊN MÁY TÍNH (Dễ Nhất)

👉 Cách 1A: Dùng Python (Nếu cài Python)

Mở Command Prompt (Windows) hoặc Terminal (Mac/Linux)
Cd tới thư mục MediPOS: 
cd C:\Users\YourName\OneDrive\Tài liệu\HTML
Chạy web server Python: 
python -m http.server 8000
Mở browser và vào: 
http://localhost:8000
✅ Sẵn sàng! Chia sẻ URL http://localhost:8000 với máy tính khác trên cùng mạng

👉 Cách 1B: Dùng Node.js (Nếu cài Node)

Cài serve globally: 
npm install -g serve
Cd tới thư mục: 
cd C:\Users\YourName\OneDrive\Tài liệu\HTML
Chạy: 
serve
Truy cập URL hiển thị trên màn hình

2️⃣ GITHUB PAGES - Host Miễn Phí (Nên Chọn)

Tạo tài khoản GitHub tại github.com (nếu chưa có)
Tạo repository mới tên: medipos
Clone repository: 
git clone https://github.com/your-username/medipos.git
Copy tất cả file MediPOS vào thư mục vừa clone
Commit và push: 
git add .
git commit -m "Initial commit"
git push origin main
Vào Settings → Pages → Chọn main branch → Save
✅ Url: https://your-username.github.io/medipos

3️⃣ NETLIFY - Host Miễn Phí, Dễ Nhất (Khuyến Cáo)

Vào netlify.com và đăng ký tài khoản (có thể dùng GitHub login)
Nhấp "Create a new site" → "Deploy manually"
Drag & drop toàn bộ folder MediPOS vào vùng upload
Chờ deploy xong (30 giây)
✅ Sẵn sàng! Nhận URL public để chia sẻ

💡 Cập nhật file:

1. Sửa file trên máy
2. Quay lại Netlify
3. Drag & drop thư mục để update
4. Hoặc sử dụng CLI: npm install -g netlify-cli
   Sau đó: netlify deploy

4️⃣ VERCEL - Host Siêu Nhanh (Cao Cấp)

Vào vercel.com và đăng ký (GitHub login tốt nhất)
Import project từ GitHub hoặc upload folder
Chỉnh cấu hình (để mặc định, ấn Deploy)
✅ Nhận URL: https://medipos-abc123.vercel.app

💡 Tự động deploy:

Mỗi lần bạn push code lên GitHub
Vercel sẽ tự động deploy (vô cùng tiện!)

5️⃣ VPS/HOSTING RIÊNG - Chuyên Nghiệp (Nâng Cao)

🖥️ Các nhà cung cấp phổ biến:

  • Việt Nam: TopHost, VHOST, GOV.VN
  • Quốc tế: DigitalOcean, Linode, AWS, Google Cloud

📋 Quy trình cơ bản:

Thuê VPS hoặc hosting
Cấu hình domain name
Setup web server (Apache/Nginx)
Upload file via FTP/SFTP
Cấu hình SSL (HTTPS)
⚠️ Túy chỉnh để có database backend

  • Mở URL trên 2 máy tính khác nhau
  • Làm giao dịch trên máy 1
  • Xem máy 2 có cập nhật không?
  • 🚨 LƯU Ý: Data hiện tại CHƯA đồng bộ realtime (cần backend để thực hiện)

🚀 Nâng Cao: Thêm Backend (Tùy Chọn)

💡 Điều này giúp:
  • ✓ Lưu dữ liệu trên server (không bị mất)
  • ✓ Đồng bộ data 100% realtime giữa các máy
  • ✓ Tạo account/password cho nhân viên
  • ✓ Lịch sử chi tiết và audit log

🔧 Yêu cầu backend:

Thay LocalStorage bằng API calls:

Ví dụ cũ: dataManager.addProduct(product)
         → Lưu vào localStorage

Ví dụ mới: fetch('/api/products', {
    method: 'POST',
    body: JSON.stringify(product)
})

💰 Giải pháp sẵn có:

  • Firebase: Setup dễ, rẻ, phù hợp
  • Supabase: PostgreSQL + realtime
  • Node.js + MongoDB: Tự code, linh hoạt
  • Python + Flask/Django: Bền vững

🆘 Xử Lý Sự Cố

❌ "Không thể mở file"

  • ✓ Kiểm tra tất cả file .js, .css trong cùng thư mục
  • ✓ Không nên mở qua UNC path (\\server\share)
  • ✓ Dùng http:// hoặc file:/// path thay vì drag file

❌ "Localhost từ chối kết nối"

  • ✓ Kiểm tra port 8000 có bị dùng không: lsof -i :8000
  • ✓ Thử port khác: python -m http.server 9000
  • ✓ Tắt firewall tạm thời

❌ "Data mất sau deploy"

  • ✓ Dữ liệu lưu ở browser localStorage → reload page vẫn có
  • ✓ Khi đổi máy → backup + restore JSON
  • ✓ Cần backend database nếu muốn chia sẻ data

✨ Đề Xuất Cho Bạn

1️⃣ Công ty nhỏ (1-3 máy):

👉 Localhost + Python
   Hoặc: Mở file trực tiếp trên mỗi máy

2️⃣ Công ty vừa (3-10 máy):

👉 Netlify (deploy 1 lần, dùng mãi)
   Chia sẻ URL cho nhân viên

3️⃣ Cần data sync hoàn toàn:

👉 Netlify + Firebase
   Hoặc: VPS riêng + Backend
